Sync the list of installed modules (and their installed versions) of an
Odoo project from the ``odoo_cloc`` webhook exposed by the customer
instance, instead of importing them manually with the *Import modules*
wizard.

A daily scheduled action keeps every project flagged for synchronization
up to date.

Configuration
=============

On each project (Odoo MCA > Projects):

1. Set **Odoo Cloc URL** to the base URL of the customer instance (it
   must have the ``odoo_cloc`` module installed).
2. Optionally set **Cloc Token** if the customer instance defines the
   ``odoo_cloc.webhook_token`` system parameter.
3. Enable **Sync Modules from Odoo Cloc** to include the project in the
   daily scheduled action *Odoo Projects - Sync modules from Odoo Cloc*.

Usage
=====

Open a project and click **Sync from Cloc** to fetch the installed
modules and their versions immediately, or wait for the daily scheduled
action.
